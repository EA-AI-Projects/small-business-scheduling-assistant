# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `EA-AI-Projects/small-business-scheduling-assistant`. The GitHub Project board tracks work state. Follow `doc/TEAM_AGREEMENT.md` for ownership, approval, review, and merge rules.

Use `gh issue create`, `view`, `list`, `edit`, `comment`, and `close` from this repository. Link parent and sub-issues with GitHub sub-issues where available, and record dependencies explicitly. When a skill says "publish to the issue tracker," create a GitHub issue; when it says "fetch the relevant ticket," read that issue.

PRs as a request surface: no.

The repository's next-owner labels remain `needs-owner-input` and `agent-owned`; `blocked` records a named dependency. The triage labels are separate classifications and do not replace those ownership labels.
